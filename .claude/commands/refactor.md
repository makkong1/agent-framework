# Refactor (`/refactor`)

## 전제

가능하면 **`/review` 이후**에 사용한다. 동작 변경이 없어야 할 때는 리그레션 범위를 명시한다.

## 유형 (하나 또는 병행)

- **구조** — 모듈 경계, 네이밍, 중복 제거
- **성능** — 측정 전제(병목)가 있을 때만
- **가독성** — 제어 흐름·에러 처리 정리

## 이 프로젝트에서

- 하네스·실행 로직: `scripts/execute.py` 등
- 리팩터 후 **`/test`** 로 `scripts/test_execute.py` 통과 확인

## 금지

- 동작 의도를 바꾸는 "리팩터" (그건 기능 변경 → 별도 설명·리뷰)
