# Troubleshooting (`/fix`)

## 언제

에러 로그, 버그, "안 돼", 재현 실패, CI 실패 등.

## 단계

1. **증상** — 메시지·스택·환경(로컬/CI) 기록
2. **재현** — 최소 재현 절차 또는 "재현 불가"와 이유
3. **원인** — 가설 → 코드/로그로 확인
4. **수정** — 최소 변경
5. **검증** — `/test` 또는 변경에 맞는 명령 (이 프로젝트: 예) `python3 -m pytest scripts/test_execute.py`

## 출력

- 원인 요약
- 변경 요지
- 검증에 쓴 커맨드와 결과
